# AppleOS

Arch-based distro with **Apple Shell** desktop (macOS-style on labwc:
top menu bar, bottom dock, Spotlight). Online GUI installer,
Wi-Fi from the live session, auto updates from GitHub. EN/RU.

```bash
./build.sh   # auto: full ISO (native on Arch, Docker elsewhere, minimal fallback)
```

## Apple Shell — keybinds

| Keys | Action |
|---|---|
| Super+Space / Super+D | Spotlight / app menu |
| Super+T | Terminal (foot) |
| Super+W | Browser |
| Super+E | Files |
| Super+I | Apple Shell settings |
| Super+Q | Close window |
| Super+F | Fullscreen |
| Super+V | Clipboard |
| Super+Shift+5 | Screen record |
| Super+Shift+C | Color picker |
| Super+Ctrl+Space | Emoji |
| Super+M | Minimize |
| Super+arrows | Screen halves |
| Super+1..4, Ctrl+Left/Right | Workspaces |
| Super+Tab | Window switcher |
| Super+L | Lock |
| Super+V / Alt+V | Clipboard / delete |
| Print / Shift+Print | Screenshot / fullscreen |
